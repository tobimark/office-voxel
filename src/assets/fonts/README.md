# Fusion Pixel 12px

Unmodified Simplified Chinese monospaced font from the official [Fusion Pixel
Font 2026.09.01 release](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01).
Original file: `fusion-pixel-12px-monospaced-zh_hans.otf.woff2` (658,024 bytes).
Renamed locally to `fusion-pixel-12px-zh_hans.woff2`; no glyph subsetting.

The font supports Latin and CJK text; use 12px or integer multiples for
the original pixel grid. The application ships the font locally, without a CDN.
